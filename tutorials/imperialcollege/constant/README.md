# constant/engineDict

This file defines the engine mesh setup used by the `imperialcollege` tutorial. It is consumed by the mesh-generation workflow to describe the moving parts of the case, the remeshing schedule, and the local mesh controls applied to each region.

## Purpose

`engineDict` brings together the information needed to generate the engine mesh consistently across time:

- the remeshing time range and step size
- global mesh sizing and region refinement
- patch-specific motion definitions
- patch-specific mesh controls and layer settings

## Main Sections

### `times`

The list of mesh times is loaded from `constant/meshTimes`:

- `times (#includeIfPresent "${FOAM_CASE}/constant/meshTimes");`

This allows the tutorial to keep the remeshing instants in a separate file that can be regenerated by the case scripts.

### `remeshControl`

Controls the time window in which remeshing is considered and how often the mesh state is sampled:

- `startInstant`: first remesh instant
- `endInstant`: last remesh instant
- `stepSize`: time increment used by the remeshing logic
- `forcedRemeshInstants`: explicitly forced remesh times

### `meshControl`

Defines the base mesh resolution and region-based refinement for the case:

- `cellSize`: base cell size for the generated mesh
- `insidePoints`: points used to establish regions inside the geometry
- `patchInfo`: default patch grouping for static walls
- `surfaceRefinement`: refinement level applied near surfaces
- `regionRefinement`: geometric refinement zones such as the truncated cone and chamber regions
- `layerControl`: boundary-layer generation settings

### `patches`

Defines the moving and fixed patches in the engine:

- `piston`: translation motion driven by a crank-connecting-rod model
- `valve`: moving valve surfaces with surface-based refinement
- `liner`: scaling motion coupled to piston motion
- `outlet`: fixed outlet patch settings

Each patch can override the global mesh controls with its own `meshControl`, including local refinements, patch grouping, and layer settings.

## Notes

- `engineDict` is designed to work with the tutorial scripts in this folder, especially `Allmesh` and `Allrun`.
- Changes to motion parameters or refinement levels can affect remeshing times and mesh compatibility, so they should be made carefully and validated with the case tools.
- The dictionary uses OpenFOAM syntax and includes nested dictionaries and file references, so keep formatting consistent when editing it.
